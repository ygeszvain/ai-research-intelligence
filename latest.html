AI Research Intelligence · Evidence before enthusiasm

Control the contracts around the model.

Today’s strongest research signal is not a new general capability. It is a control-plane pattern: useful agent memory should be valued by downstream work saved; consequential tool calls should be authorized by deterministic rules grounded in the user’s request; and safety scores should be trusted only when the construct, grader, uncertainty, and deployment surface are documented.

CapLite: Prompt-Injection Defense for Small Language Model Agents without Model-Written Security Artifacts

What changed

Rather than asking the agent model to write the policy it will later obey, CapLite derives tool roles from schemas, commits write calls before any untrusted tool result is read, restricts effect-bearing arguments to exact values in the user request, and enforces the result in deterministic code. The model may select candidates or compose content, but it does not define authorization.

Where the number comes from. Main ASR pools 15 × 929 tool-goal episodes. Utility under attack uses 949 attacked task pairs per model. Token cost averages benign and attacked episodes. Per-model comparisons use task-resampled 95% bootstrap intervals.

Methodological critique

  • Strength: broad model sweep, matched defense ports, ablations, adaptive attacks aimed at the design, per-episode tables, and a construction-level integrity argument.
  • Material tradeoff: zero attacks are purchased partly through narrower authority. Utility under attack is 21 points below the undefended agent; missing request-grounded identifiers cause confirmation or failure.
  • External validity: all results use one benchmark family (AgentDojo’s four suites), temperature 0, and simulated tools. Free-text payload content is outside the strongest guarantee.
  • Artifact status: the paper states that code and per-episode outcome tables are released and identifies Apache-2.0 for guard code, but no canonical repository was linked from the inspected abstract page. Treat reproducibility as partial until the repository is independently located and pinned.

Prior-work comparison

CaMeL, Progent, IPIGuard, and DRIFT enforce programs, policies, graphs, or constraint lists produced by the agent model. CapLite moves the authorization basis to schemas plus user-stated values. This narrows expressiveness but removes the model-authored policy from the trust boundary.

Peiwen Li et al. · Yale, Tsinghua, Goodvision AI · arXiv:2611.17316v1

Abstract · Full paper · Anonymous artifact

100task chains
21.0→25.7%27B resolve
−17%steps
−11%total tokens

What changed

CoReMem values pieces of a completed coding trajectory by rerunning the next task from the same inherited repository with and without each segment. It keeps compact “anchors”—repository locations and executable checks—then trains the actor with an outcome-first, effort-charging reward. Memory value is credited only to steps whose provenance shows they used memory-supplied anchors.

Quantitative claim trace

On the reported 27B actor, no memory resolved 21.0% of tasks; CoReMem resolved 25.7%, with average steps falling to 29.2 and total cache-aware tokens to 28.5k. Across three post-trained open-weight actors, resolve per total token improved 38–46% (41% average). The frozen memory alone reduced steps on all six tested actors without lowering resolution.

Mechanism evidence. The compact memory delivered 1.32 used anchors per 1,000 characters versus 0.92 for MemOp, 0.19 for ReasoningBank, and 0.14 for Mem0. Removing provenance-gated credit made a misplaced memory cost the 27B actor 2.1 steps; the full method reduced that penalty to 0.3.

Methodological critique

  • Strength: disjoint repositories across train/test, controlled next-task counterfactuals, cost-inclusive metrics, misplaced-memory controls, mechanism ablations, and API-model extensions.
  • Causal boundary: the intervention is memory text while inherited repository state is fixed. This estimates memory value conditional on the prior agent’s actual edits, not value under a clean or gold repository.
  • Scale: ChainSWE has 100 chains split in half; the paper reports intervals/tests for many comparisons, but the small chain count limits precise subgroup conclusions.
  • External validity: main experiments use Python repositories and mini-swe-agent; no wall-clock latency or energy; long-history refresh and stale-anchor handling remain open.
  • Artifact status: code exists behind an anonymous review link; durable ownership, license, tagged release, and independent reproduction were not verified.

Prior-work comparison

Mem0, MemOp, and ReasoningBank retain experience but often increase total token cost. CoReMem’s distinctive move is to value memory on the next task, preserve executable/localization anchors, and charge both writer and reader costs rather than treating memory length or retrieval relevance as the objective.

Building strong safety evaluations

Ruth Appel et al. · Anthropic Engineering · published November 13, 2026

Primary article

16policy areas
7languages
100 / 1,000suggested floors
60→94%configuration example

What changed

Anthropic consolidates operational recommendations for construct validity, causal versus observational designs, realistic scenario generation, safe sandboxes, grader calibration, preregistration, configuration equivalence, continuous testing, uncertainty, and responsible disclosure. The article explicitly ties recommendations to recent evaluation incidents and system-card practice.

Quantitative claim trace

  • Current single-turn harmless-response rates are reported at 94–98% for recent models, indicating saturation; multi-turn results vary more.
  • Anthropic treats 100 items as a floor for complex multi-turn evaluations and 1,000 as a floor for simpler single-turn evaluations—not universal power calculations.
  • For a Claude Fable 5.1 self-harm evaluation example, targeted system-prompt mitigations produced 60% appropriate responses on the API versus 94% on claude.ai, a 34-point configuration gap.

Methodological critique

  • Strength: direct operational experience, explicit failure examples, clear distinctions among construct, internal, external, and causal validity, and actionable grader checks.
  • Evidence limitation: this is prescriptive engineering guidance, not a preregistered comparative study. The sample-size floors are heuristics; power depends on prevalence, dependence, variance, effect size, and stopping rules.
  • Transparency limitation: many underlying datasets, grader prompts, and incident traces are not included in this article; reproducibility depends on linked system cards/toolkits.
  • Enterprise implication: adopt the documentation and validation contract first; do not import Anthropic’s thresholds without domain-specific power analysis and internal risk tolerance.

Prior-work comparison

The guidance imports reforms familiar from psychology—preregistration, measurement validity, complete statistics—and adapts them to non-deterministic model behavior, LLM graders, deployment surfaces, and sandbox risk. It complements benchmark-centric work by treating the evaluator itself as a governed production system.

Cross-paper synthesis

From model-centered systems to governed evidence flows

1. Propose

Models generate candidate plans, memories, judgments, and tool arguments. Their flexibility is useful, but their output is not self-authenticating.

2. Bind

Deterministic or independently governed layers bind proposals to user-stated authority, repository state, versioned constructs, and executable checks.

3. Verify

Outcomes, grader agreement, uncertainty, cost, and surface-specific behavior become replayable evidence—not a single benchmark score.

Enterprise AI Architecture Implications · Independent Analysis

A 12–24 month consequence-aware control plane

The reviewed research does not establish what any particular enterprise already has. The following is a target pattern whose sequencing depends on internal architecture, data classification, identity model, regulatory obligations, threat model, and operating maturity.

Applications & humansIntent capture · confirmation · review
Agent orchestrationPlan · trace · rollback · hindsight credit
Policy & identityEffect mediator · authorization · budgets
Context & knowledgeVersioned anchors · provenance · retention
Evaluation planeEvidence contracts · graders · drift · replay

Shared enabling foundations

Identity and policy

Authenticated intent, authority-bearing fields, least privilege, effect budgets, and policy ownership unlock safe action mediation.

Evidence and provenance

Immutable traces, repository/data versions, anchor lineage, grader/model versions, and signed run manifests unlock replay and accountability.

Evaluation and operations

Paired experiments, uncertainty, cost telemetry, drift detection, sandbox controls, and human escalation unlock risk-adjusted experimentation.

Internal context required before implementation: current model gateway and agent framework; tool inventory and effect taxonomy; IAM and delegated-authorization semantics; data residency/retention; regulated workflows; existing eval/observability stack; change-management capacity; acceptable false-denial, latency, and review budgets.

Implementation priorities

One reversible 90-day sequence

Days 0–15

Inventory consequential tools, evals, graders, surfaces, trace coverage, and owners. Select one low-risk sandbox workflow.

Days 16–35

Add an evaluation evidence contract and blind human calibration sample. Establish baseline quality, cost, latency, and risk.

Days 36–60

Shadow the deterministic effect mediator and anchor memory. Execute nothing automatically; inspect disagreements.

Days 61–90

Run adversarial replay, paired statistics, and rollback drills. Decide independently for each capability: advance, revise, or stop.

Minimum measurement set

  • Task success and expert-rated quality
  • Unauthorized-effect and false-denial rates
  • Grader–human and human–human agreement
  • Token, latency, compute, and review cost
  • Memory anchor reuse and stale-anchor rate
  • Rollback completeness and incident containment

Non-negotiable stop conditions

  • Any uncontrolled external write or credential exposure
  • Evaluation conclusion changes under a reasonable grader/rubric perturbation
  • Provenance cannot reconstruct the decision
  • Utility, latency, or human-review burden exceeds predeclared tolerance
  • Transfer evidence remains confined to synthetic tasks after the experiment window
Knowledge reinforcement

What to remember tomorrow

Five durable propositions

  1. A model-generated policy is still model output; it is not automatically a security boundary.
  2. Memory should be selected by downstream value net of write/read cost, not by relevance alone.
  3. Evaluator validity is part of product reliability; grader changes can masquerade as model changes.
  4. Surface, harness, prompt, tool, and policy configuration are part of the evaluated system.
  5. Replayable effects, provenance, and stop controls matter more than a benchmark headline for enterprise adoption.

  • Evaluation: Is the construct defined, the grader calibrated, and uncertainty visible?
  • Transfer: Which deployment surface and threat model were actually tested?
  • Reversibility: Can the experiment be stopped, replayed, and rolled back without production harm?
